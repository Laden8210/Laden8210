<img src="./assets/nasa-ph-logo.jpg" align="right" width="280" alt="NASA PH logo" />

Hi! I'm **John Michael Domingo**, a **Full Stack & Mobile Developer** with **[NASA PH](http://nasa-ph.com/)**, a Filipino developers' collective based in Koronadal, South Cotabato (est. 2024).

I architect end-to-end applications across **web, iOS, and Android**, specializing in the **Next.js / Nest.js** and **Laravel** ecosystems with hands-on **React Native** experience. I work with **Infrastructure as Code (Terraform)** and **CI/CD (GitHub Actions)**, and integrate **RAG, vector databases, and MCP** into production systems on **GCP and AWS**.

- 💼 Full Stack Developer at **ai2aim.ai** (Canada-based)
- 🧠 Architected **Hivemind**, a unified multi-tenant AI platform
- 📦 Shipped **20+ projects** as a freelancer since 2023
- 🔐 Exploring security: pentesting, OWASP Top 10, network security
- 🤖 Into hackathons, robotics & IoT prototypes, and autonomous AI agents
